# Oversampled data - data dictionary

Two refreshes were generated by `pipeline/oversampling/generator.py` and orchestrated by the `sdi_oversampling` Airflow DAG.
Each refresh appends one calendar quarter to the 2023-2025 base dataset; nothing in the base is modified.

| Refresh | Window | Template window (same quarter last year) | SKUs re-priced (SCD-2) |
|---|---|---|---|
| `refresh_01_2026Q1` | 2026-01-01 → 2026-03-31 | 2025-01-02 → 2025-04-01 | MED030, MED025, MED003, MED002, MED036, MED039 |
| `refresh_02_2026Q2` | 2026-04-01 → 2026-06-30 | 2025-04-02 → 2025-07-01 | MED018, MED010, MED029, MED056, MED048, MED045 |

## Rows generated per file

| File | refresh_01_2026Q1 | refresh_02_2026Q2 | Growth factor (R1 / R2) | Malformed injected (R1 / R2) |
|---|---|---|---|---|
| `01_master_data.csv` | 63 | 63 | 1.000 / 1.000 | 0 / 0 |
| `02_manufacturing_data.csv` | 56 | 35 | 0.984 / 1.049 | 1 / 0 |
| `03_manufacturer_delivery_data.csv` | 105 | 53 | 1.003 / 1.003 | 1 / 1 |
| `04_warehouse_data.csv` | 16,004 | 14,470 | 1.250 / 1.250 | 34 / 31 |
| `05_pharmacy_sales_data.csv` | 25,969 | 17,337 | 0.900 / 0.900 | 77 / 52 |
| `06_hospital_demand_data.csv` | 2,268 | 2,268 | 1.033 / 1.036 | 6 / 6 |
| `07_iot_streaming_data.csv` | 25,548 | 22,132 | 0.997 / 0.990 | 40 / 29 |

Malformed rows are deliberate (null SKU, negative price/quantity, impossible date `2026-13-45`, duplicate key) and are
caught by the staging validation rules R2/R4/R5/R7. IoT files are replayed through the streaming API instead of the landing zone.
